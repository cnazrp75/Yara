# YARA — Your AI Response Assistant

دمو تعاملی تیم **Golden Gate** برای رویداد **پُل** (چارگون، مهر ۱۴۰۵).

YARA یک کارشناس پشتیبانی هوش مصنوعی برای نرم‌افزارهای سازمانی On-premise است. به تماس مشتری گوش می‌دهد و با اجازه ادمین، مشکل را روی سرور خود مشتری تشخیص می‌دهد. اصلاح را اول در Sandbox آزمایش می‌کند و بعد از تأیید انسانی اجرا می‌کند. اگر مشکل باگ باشد، تیکتی کامل با شواهد می‌سازد.

## اجرا

```bash
npm install
npm run dev
```

بعد آدرس `http://localhost:5173` را در Chrome باز کنید.

## دو حالت دمو

| حالت | توضیح |
|---|---|
| **صدای زنده** | مکالمه واقعی با Agent صوتی ElevenLabs. Agent با Client Tools داشبورد را زنده کنترل می‌کند. راهنمای ساخت Agent: [AGENT_SETUP.md](AGENT_SETUP.md) |
| **دمو آفلاین** | گفت‌وگوی از پیش نوشته‌شده برای سه سناریو. بدون اینترنت و میکروفون کار می‌کند؛ پلن B روی صحنه. |

## صفحه‌ها

- **معرفی:** مسئله، ارزش پیشنهادی، مقایسه فرایند فعلی با YARA
- **دمو زنده:** تلفن، متن زنده مکالمه، مسیر ۹ مرحله‌ای حل مسئله، کنسول تشخیص روی سرور، پرونده هوشمند، و تأییدهای ادمین
- **داشبورد پشتیبانی:** نمای کارشناس (تیکت‌های ساخته‌شده در دمو هم این‌جا اضافه می‌شوند)
- **ارزش اقتصادی:** ماشین‌حساب با فرض‌های قابل تغییر (همان مدل مستند PDF)
- **معماری و امنیت:** معماری کاملاً محلی، پله‌های اختیار و محافظ‌های ایمنی

## ساختار کد

```
src/
  engine/
    store.js          state سراسری (مشترک بین ابزارهای Agent و UI)
    tools.js          Client Toolهای ElevenLabs + محافظ‌های ایمنی در کد
    mockData.js       داده‌های ساختگی: مشتری، دانش، سناریوها، لاگ‌ها
    script.js         گفت‌وگوهای حالت آفلاین
    useYaraSession.js اتصال به ElevenLabs (@elevenlabs/react)
  components/         تلفن، مسیر حل مسئله، متن مکالمه، کنسول و پرونده
  pages/              صفحه‌های اپ
```

## یادداشت صداقت

- همه داده‌ها، سازمان‌ها، لاگ‌ها و محصول «نامه‌نگار» **ساختگی‌اند**.
- در حالت زنده، صدا و LLM از ElevenLabs (ابری) استفاده می‌کنند. در نسخه واقعی، همین ابزارها و محافظ‌ها با مدل‌های محلی (LLM متن‌باز، Whisper و TTS فارسی) اجرا می‌شوند. این نکته داخل خود اپ هم ذکر شده است.
